# Creating Windows Server 2022 Virtual Machine

## Objective

Create a virtual machine that will host Windows Server 2022 for Active Directory and system administration practice.

## VM Configuration
| VM Name | Server01 |

| Operating System | Windows Server 2022 |
| RAM | 4GB |
| CPU | 2 Cores |
| Storage | 60GB |
| Virtualization | VirtualBox |

## Network Configuration

Initial Adapter:
- NAT

Purpose:
- Provides internet access for updates and downloads.

## Status

Virtual machine successfully created and Windows Server ISO mounted.
